# مولّد أكواد الشحن (Offline STS Token Generator)

تطبيق أندرويد بسيط يولّد أكواد شحن عدادات الكهرباء (STS Standard Transfer Specification)
بالكامل داخل الجهاز، بدون أي اتصال بالإنترنت وبدون خادم خارجي.

## الأساس التقني

منطق التشفير (DES / خوارزمية STA / CRC / اشتقاق مفتاح العداد / بناء التوكن) في
`app/src/main/assets/sts-core.js` تم استخراجه من ملف `STSDll.dll` الأصلي
(المرفق سابقًا ضمن "Client.zip") بتفكيك شيفرة .NET IL وإعادة بنائها، والتحقق
من تطابق النتائج مع الملف الأصلي عبر مئات الاختبارات العشوائية:

- DES: مطابق تمامًا (متحقق بمتجهات الاختبار القياسية وعشوائية).
- خوارزمية STA (16 دورة الخاصة بالشركة): مطابقة 100%.
- `MakeMeterKey` (اشتقاق مفتاح العداد من VK1/VK2): مطابق 100% على 180 حالة عشوائية بأنواع DKGA الثلاثة.
- `TokenCreate` (بناء التوكن النهائي 20 رقمًا): مطابق 100% على 300 حالة عشوائية.

## ⚠️ نقطة غير مؤكدة: رقم العملية TID

لم أجد داخل الشفرة المفككة الدالة التي تحسب TID من التاريخ (غالبًا لأنها تعتمد على
قاعدة بيانات/عدّاد تسلسلي على الخادم وليست حسابًا رياضيًا بحتًا). التطبيق يستخدم
افتراضًا شائعًا في عدادات STS: **TID = عدد الدقائق منذ 2014-01-01 00:00:01**.

استخدم تبويب **"معايرة / تحقق"** داخل التطبيق مع كود حقيقي صادر فعلاً من برنامجك
الأصلي (نفس رقم العداد والكمية ووقت الإصدار) للتأكد من صحة هذا الافتراض، أو لإيجاد
الإزاحة الصحيحة إن اختلفت.

## قبل أول استخدام: أدخل بيانات مجموعتك

من تبويب "الإعدادات" داخل التطبيق أدخل (تُحفظ محليًا فقط على الجهاز):
- Supply Group Code (SGC) — يظهر في إيصالات الصرف.
- Tariff Index (TI)
- Key Revision Number (KRN)
- Key Type (KT)
- VK1 و VK2 (مفاتيح البيع) — هذه موجودة مشفّرة داخل `MeterClient.ini` الأصلي.
  **لم أقم بفك تشفيرها** لأنها سرّ تجاري/أمني يخص مزوّد النظام (أي شخص يملكها
  يمكنه توليد أكواد مقبولة لكل عدادات المجموعة). احصل عليها من الجهة التي باعتك
  الترخيص، أو من ملفات الإعداد الأصلية إن كانت لديك صلاحية الوصول إليها بصيغتها
  الصريحة.
- DKGA: طريقة اشتقاق المفتاح (غالبًا 3).

## البناء والتشغيل

1. افتح مجلد `android/` هذا بالكامل في **Android Studio** (Open an existing project).
2. سيطلب منك Android Studio مزامنة Gradle — اقبل (سيُنزِّل تلقائيًا كل ما يلزم
   طالما جهازك متصل بالإنترنت وقتها فقط؛ التطبيق نفسه بعد التثبيت لا يحتاج إنترنت إطلاقًا).
3. وصّل جوالك أو استخدم محاكيًا، ثم اضغط Run ▶، أو ابنِ APK من
   Build → Build Bundle(s)/APK(s) → Build APK(s).

> ملاحظة: لم أتمكن من بناء المشروع فعليًا في بيئتي الحالية (لا يوجد اتصال
> إنترنت لتنزيل Gradle/SDK هنا)، لذا الخطوة الأولى بعد فتحه في Android Studio
> ومزامنته مهمة للتأكد من عدم وجود خطأ بسيط في الإعداد.

## ملاحظات أمنية مهمة

- التطبيق **لا يطلب إذن الإنترنت** إطلاقًا (تعمّدت ذلك) — فلا توجد طريقة لتسريب
  المفاتيح عبر الشبكة.
- `android:allowBackup="false"` لمنع نسخ بيانات التطبيق (ومنها VK1/VK2) عبر
  النسخ الاحتياطي السحابي لجوجل.
- الشاشة محمية بـ `FLAG_SECURE` لمنع لقطات الشاشة والتسجيل أثناء استخدام التطبيق.
- مع ذلك، أي شخص يفتح قفل جوالك يمكنه توليد أكواد. ضع قفل شاشة قوي (بصمة/رمز).

## الاستخدام القانوني

هذه الأداة لإعادة تنفيذ وظيفة برنامج ترخّصت باستخدامه فعلاً، على جهازك الخاص،
لنفس الغرض (توليد أكواد لعدادات تديرها). تأكد أن هذا ضمن حقوق الترخيص الذي
تملكه قبل الاستخدام أو التوزيع.
